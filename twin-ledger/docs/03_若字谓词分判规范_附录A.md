# 机备账 · "若"字谓词分判规范（附录）

**文档编号**: ML-SCHEMA-2026-001-v1.1-附录A
**日期**: 2026-08-14
**定位**: schema v1.1 §3.2 最小谓词集的补充规范——"若"字多义分判
**性质**: 本文档是"若"字谓词判定的可执行标准，供铸砖与校验复用

---

## 一、问题的提出

"若"字在《道德经》中身兼多义，横跨喻边与逻辑边两种边类型。schema v1.1 §3.2 中"若"同时出现在：

| 边型 | 谓词 |
|------|------|
| 喻 | 若、如、似 |
| 逻辑 | 若(条件) |

不给出分判规则，铸砖时会产生歧义：同一"若"字，判为喻边则不传递因果（保守），判为逻辑边则进入推理（激进）——**判错方向影响整个图谱的推理性与可信度**。

---

## 二、全书"若"字实测统计（41 处）

基于 `daojing_database_v2.json`（含本次补回的第67章原文）全量扫描：

| 用法 | 判据 | 例 | 处数 | 占比 |
|------|------|-----|:----:|:----:|
| **喻·比拟**（像/如同） | 可替换为"像" | 上善若水（8）、若畏四邻（15）、大成若缺（45） | 36 | 87.8% |
| **条件·假设**（如果） | 可替换为"如果" | **若肖（67）**、若使民常畏死（74） | 2 | 4.9% |
| **推理·连词**（乃/才） | 可替换为"乃/才"（王弼注："若，乃也"） | 若可寄天下（13）、若可托天下（13） | 2 | 4.9% |
| **反问·疑词**（如何） | 可替换为"何" | 相去若何（20） | 1 | 2.4% |

**关键事实**：
1. 喻义占绝对主导（87.8%），条件/推理义合计不足 10%
2. **三种非喻用法各有专属文本证据**，不重叠
3. 第13章、第67章、第74章、第20章四章，覆盖全部非喻用法

## 三、分判规则（三层递进，按顺序执行）

### 第一层：替换检验（主判据）

> 将"若"分别替换为"像"与"如果"，看哪个读得通：

| 替换结果 | 判定 | 边型 |
|---------|------|------|
| "像"读得通，且后半是相似物 | 喻 | 喻 |
| "如果"读得通，且后半是结果 | 条件 | 逻辑 |
| 两者皆不通 | **进入第二层** | — |

### 第二层：推理连词检验（"若"=乃/才）

> 替换为"乃/才"读得通 → **推理·逻辑边**（王弼注依据）

```
第13章：故贵以身为天下，若可寄天下 → 乃可寄天下 ✅
        爱以身为天下，若可托天下   → 乃可托天下 ✅
```

### 第三层：优先规则（兜底）

> 两可或无法判定时，**从喻不从逻辑**。

理由：喻边不传递因果，判错最坏是"少推一步"；逻辑边判错会"错推"，污染整个推理链。**不确定时保守，符合"小澄真"只塑形不改骨的精神。**

## 四、四案例详解（供校验复用）

### 案例1：第13章"若可寄天下"——推理（乃/才）

```
原文：故贵以身为天下，若可寄天下；爱以身为天下，若可托天下。
替换"像"：像可寄天下       ❌ 不通
替换"如果"：如果可寄天下    ❌ 别扭
替换"乃/才"：乃可寄天下     ✅ 通（王弼注：若，乃也）
判定：推理·逻辑边
```

**义理**：前半"宠辱若惊""贵大患若身"为喻（像受惊/像身体）；后半"若可寄天下"转为推理（乃可托付）——一章内"若"从喻滑向推理，完成从"有身之患"到"无身之公"的论证闭环。

### 案例2：第67章"若肖"——条件（如果）

```
原文：天下皆谓我道大，似不肖。夫唯大，故似不肖。若肖，久矣其细也夫！
替换"像"：像肖         ❌ 不通（"肖"本身即"相似"义，再加"像"重复）
替换"如果"：如果（道与物）相似 → 早就渺小了 ✅ 通
判定：条件·逻辑边（反证推理）
```

**义理**："若肖"是反证条件——若道真的与具体事物相似，早已沦为渺小；故"似不肖"正是"大"的证明。与第74章"若使民常畏死"同属条件用法。

**历史纠错**：此例曾因数据库第67章原文缺失（original_text 为空）被误判为"全书无此词"——已补回原文，纠错确认。

### 案例3：第15章"若畏四邻"——喻（像）

```
原文：豫兮若冬涉川，犹兮若畏四邻
替换"像"：像畏惧四邻一样 ✅ 通
替换"如果"：如果畏惧四邻    ❌ 不通
判定：喻边
```

**义理**："若畏四邻"是明喻，描述善为士者谨慎之态——虽"若"后跟动词短语，但仍是"像+动"的比喻，非假设条件。**注意：不可因"后跟动词"即判条件，须以替换检验为准。**

### 案例4：第74章"若使民常畏死"——条件（如果）

```
原文：若使民常畏死，而为奇者，吾得执而杀之，孰敢？
替换"如果"：如果使民众常畏惧死亡 ✅ 通
判定：条件·逻辑边
```

**义理**：典型假设句，"若使"连用引出条件情景，后接结果。是"若"作条件义最无争议的例证。

## 五、schema 落点（§3.2 注释建议 · v1.1 修订）

### 5.1 修订原则（回应 DeepSeek 反馈）

**谓词保持单字"若"，不物理分槽。** 原因有二：

1. **原字优先**：schema 铸造规则第5条承诺"原文核心词优先"。"若可/若使/若肖"是"若+补足语"的再加工，把补足语黏进谓词，是让机器方便凌驾于文本本相之上——在"为学日益"的路上又偷偷砌了一块砖。
2. **edge_type 已承载边型**：edge_type（喻/实/逻辑/玄）本就是必填字段。"若"的歧义天然由 edge_type 消解，无需再造谓词分槽——**谓词管"字"，edge_type 管"型"，各司其职**。

### 5.2 分判落点（谓词单字 + edge_type + note）

```json
{ "subject": "上善-8", "predicate": "若", "edge_type": "喻",
  "object": "水-8", "source": "8.上善若水", "status": "ACTIVE" }

{ "subject": "道-67", "predicate": "若", "edge_type": "逻辑",
  "object": "肖-67", "source": "67.若肖，久矣其细也夫",
  "status": "ACTIVE", "note": "若=如果（反证条件）；替换式'若肖→如果相似'" }

{ "subject": "贵以身为天下者-13", "predicate": "若", "edge_type": "逻辑",
  "object": "可寄天下-13", "source": "13.若可寄天下",
  "status": "ACTIVE", "note": "若=乃/才（王弼注'若，乃也'）；替换式'乃可寄天下'" }
```

**note 承载**：替换式（像/如果/乃才）+ 王弼注依据——分判理由随砖入库，可溯源。

### 5.3 机器零判断：subtype 枚举字段（必填）

谓词保持单字"若"，分判由 **subtype 枚举字段（必填）**承载——机器读枚举零判断，原文不失真：

```json
{ "predicate": "若", "edge_type": "喻",   "subtype": "metaphor",      "note": "可替换'像/如同'" }
{ "predicate": "若", "edge_type": "逻辑", "subtype": "condition",     "note": "若=如果（反证条件）" }
{ "predicate": "若", "edge_type": "逻辑", "subtype": "reasoning",     "note": "若=乃/才（王弼注）" }
{ "predicate": "若", "edge_type": "喻",   "subtype": "interrogative", "note": "若=何（相去若何）" }
```

- `subtype` 枚举：`metaphor`（喻）/ `condition`（条件）/ `reasoning`（推理）/ `interrogative`（反问）
- **Validator 硬校验**：凡 predicate="若" 且 subtype 缺失或非枚举值 → **拒收入库**
- 两可时，`subtype=metaphor`（从喻不从逻辑）
- 非"若"谓词：subtype 可为 null，不强制

### 5.4 §3.2 注释修订（并入 schema v1.1）

> **"若"字分判（谓词单字 + subtype 枚举必填）**：谓词恒为单字"若"，边型由 edge_type 承载，分判由 subtype 枚举字段（必填）承载——`metaphor`（喻）/ `condition`（条件）/ `reasoning`（推理，王弼注"若，乃也"）/ `interrogative`（反问）；Validator 硬校验：predicate="若" 且 subtype 缺失或非枚举值 → 拒收。两可时，从喻不从逻辑。

**修订说明**：v1.1 初稿曾建议"若/若可/若使/若肖"物理分槽——经审核，该方案将补足语黏入谓词，违背"原文核心词优先"，已撤销。v1.1.1 修订：将"note 软注"升级为"subtype 枚举必填"——机器零判断成本，原文不失真，Validator 硬校验。

## 六、一句话结论

> **"若"字在《道德经》中四义并存（喻36/条件2/推理2/反问1，共41处），喻义主导但非唯一。分判用三层规则：替换检验（像/如果）→ 推理连词检验（乃/才，王弼注）→ 从喻不从逻辑。四个案例（第13章乃才、第67章条件、第15章喻、第74章条件）覆盖全部非喻用法，其中第67章"若肖"曾因数据库原文缺失被误判，已纠错。谓词恒为单字"若"，分判由 subtype 枚举字段（必填）承载——机器零判断成本，原文不失真，Validator 硬校验（predicate=若 且 subtype 缺失/非法 → 拒收）。此规范写入 schema §3.2 与 §6.1，不占六项机制额度（subtype 为字段级细分，非新机制）。**

*修订记录：v1.1 初稿曾建议"若/若可/若使/若肖"物理分槽 → 经审核撤销（违背"原文核心词优先"），改为"谓词单字 + edge_type + note"。*
