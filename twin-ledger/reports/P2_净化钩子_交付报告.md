## 2. 核心流程（双账本接口②落地）

```
铸砖前（回收站之前）：
  │
  ▼ 静默审查三问（小澄真）
  ① 这一章，哪一句/哪个词，是我决定'不提取'的？
  ② 这条边/这颗晶体，是文本直陈，还是我的推演？
  ③ 若在推演，是否已标注'🟠创见延伸'而非'🔵文本事实'？
  │
  ▼ 自动提取静默晶体（3 种格式）
  │   · ●：xxx（明确标记）
  │   · > 一句止语（最想强调却决定不写）
  │   · ~~损去浮尘~~（划掉的过度解读）
  │
  ▼ 人工补充（--add 成对）
  │
  ▼ 写入空白日志 silent_log.md（不入图谱）
  │
  ▼ 回收站钩子：检测净化报告 → silent_count 联动 → 入库
```

---

## 3. 三扇窗的落实

| 窗 | 落实 |
|----|------|
| 窗一（静默不入冻结令） | silent_log 独立于机备账机制，无版本约束 |
| 窗二（真正的静默不入库） | silent_log.md 是空白日志，**不属于图谱文件**；图谱中仅存 silent_count 元数据（缝5） |
| 窗三（道半冻结） | 净化报告仅记录"不提取的痕迹"，不参与任何推理 |
