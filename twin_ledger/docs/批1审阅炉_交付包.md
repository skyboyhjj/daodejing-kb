## 一、前置条件

```bash
git clone https://github.com/skyboyhjj/daodejing-kb.git
cd daodejing-kb/twin_ledger
```

在 `daodejing-kb/.env` 中添加（二选一或全配）：

```env

ARK_API_KEY=your-ark-api-key

# 月之暗面 kimi-k3
KIMI_API_KEY=your-kimi-api-key
```

### 1.3 安装依赖

```bash
pip install -r requirements.txt  # 或确保 Python 3.10+ 可用（纯标准库，无外部依赖）
```
