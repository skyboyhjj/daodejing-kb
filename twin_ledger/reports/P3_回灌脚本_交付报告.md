## 2. 核心流程（双账本接口③落地）

```
读解第N章时：
  │
  ▼ ① 跨章召回：图谱中与本章同实体的其他章砖（本体-分相双层）
  │    例：读第8章 → 召回第1章"无/有/玄/道/天地万物"（7 实体/10 提示）
  │
  ▼ ② 提示生成（非结论）：按推理策略遍历，产出提示
  │    · 逻辑/实边：权重 1.0，正常遍历
  │    · 喻边：权重 0.5，不传递因果
  │    · 玄边：权重 0.2，降权 + 提示人文语境
  │    · EXTENSION 边：标注 🟠创见（与 🔵文本 区分）
  │
  ▼ ③ 回灌响应区（强制）：读解模板第二步内嵌
  │    "回灌提示已阅：采纳/忽略/质疑（+理由≥10字）"
```

---

## 3. 关键设计落实

### 3.1 提示不结论（窗三·验证1）
- 提示语言全部为"可参考其对…的相位"——**零结论性语言**（因此/所以/必然/可以推出：0 条）
- 回灌只召回与提示，不自动推导新结论（缝6）

### 3.2 强制响应区（缝3·验证2）
```
**回灌响应（必填，≥10 字）**：
> 回灌提示已阅：采纳 / 忽略 / 质疑（选一）
> 理由：____
```
- 无此字段的读解 = 回灌未执行，不得进入回收站

### 3.3 推理策略（缝6·验证3）
| 边型 | 权重 | 策略 |
|------|:----:|------|
| 逻辑/实 | 1.0 | 正常遍历 |
| 喻 | 0.5 | 不传递因果 |
| 玄 | 0.2 | 降权 + 人文语境提示 |
