## 定位

人读账是双账本架构的"话"侧——五步协同读解报告，为人服务。

每一章读解遵循五步流程：
1. **第一步**：章旨与定位
2. **第二步**：收集实际（含回灌响应区）
3. **第三步**：智慧晶体（SPO 提取）
4. **第四步**：核心智慧晶体
5. **第五步**：意义转化

### 静默标记格式

- `●：xxx` — 明确标记的静默晶体
- `> 一句止语` — 最想强调却决定不写
- `~~损去浮尘~~` — 划掉的过度解读
